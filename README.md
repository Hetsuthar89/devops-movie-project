# DevOps Movie Ticket System

This is a simple Python CLI (Command Line Interface) project for managing a movie ticket booking system.

## Features
- Add Movie
- Book Ticket
- Cancel Ticket
- View Movies
- Search Movie

## Technologies Used
- Python
- Git & GitHub

## How to Run
1. Open terminal
2. Navigate to project folder
3. Run:
   python Devops.py
